# 行业基本面综合前5

运行 `uv run python -m alphasift.lifecycle_fundamentals`；只重建报表时加 `--report-only`。

输入为 `data/lifecycle-sector-top10-all.csv` 的全部双窗口一致候选，**不是**上一轮被截断的行业前10，也不是全体上市公司。按市场、既有行业分类分组，跨 A/B/C/D/E/F/G/H 阶段取最多5只，阶段保持原值。未分类单列。

复用本工作区 `data/fundamental_scan.py` 的采集函数及 `data/rank_fundamental_top50.py` 的财务评分函数；通过 AST 只加载指定函数，不执行旧脚本的扫描或文件写入。运行需要保留这两个既有脚本。当天成功的缓存保留原获取时间，其他候选以2并发补抓，遇供应商限流停止新请求。

综合分 = 基本面分 × 0.8 + 原双窗口一致技术分 × 0.2。技术分是形态吻合度，不是预期收益，尤其 D/E 不能解释成推荐买入。

普通公司基本面评分：自由现金流40、净债务30、盈利30，外加衰退及股权激励扣分。门槛与详细公式随 Markdown 报告输出。自由现金流为经营现金流减资本开支绝对值；净债务为总债务减现金及等价物。评分基于比率，金额按各公司财报币种显示，不把人民币和美元直接相加。最新年度为负FCF、亏损、负净资产、关键数据缺失、三年记录不完整或过旧者不入围。

金融公司不能套用普通公司FCF/负债口径：本轮缺资本充足率、资产质量、偿付能力等专门数据，所以保留原财务记录并标记待核验，**不生成貌似可比的金融前5**。REIT、公用事业等资本密集企业也可能受到这套现金流门槛的偏差影响，未入围不等于公司质量差。

输出 `data/lifecycle-industry-top5.{html,md,csv,json}`，及包含所有候选入围/排除原因的 `data/lifecycle-industry-top5-audit.csv`。完整财务缓存为 `data/lifecycle-fundamentals-all.json`。JSON及CSV保存源链接、财报期间、获取时间及评分细项。

数据为 Yahoo/yfinance 提供的年度报表加最近可用资产负债表，不是TTM、不是公告审计、不能保证最新披露。行情沿用此前扫描，不重新宣称实时。未评估估值、最新季度恶化、受限现金、债务到期、监管公告及造假风险；结果仅供进一步研究。双窗口交叉验证也不是两个独立行情源验证。
