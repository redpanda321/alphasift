# A/H 生命周期策略（v1.2）

## 每次刷新与全部历史（当前版本）

`lifecycle_ah` 每次运行重新请求全市场快照及候选股历史，不读取本地快照兜底或日线缓存。
`lookback_days: 0` 表示请求供应商全部可用复权历史（Yahoo `period=max`），不再截取五年。此模式中 A 股、美股历史均走 yfinance；数据源不保证每只股票上市以来绝无缺漏。
输出 `history_start`、`history_sessions`、`history_scope` 和 `history_retrieved_at`，可核对实际覆盖范围。
完整历史用于 D 顶部、主升浪及下跌周期判断；A 的相对低位仍用最近三年，52 周指标仍用最近 252 日，避免要求成熟公司回到几十年前的发行价。

按 XSHG/XNYS 交易日历确定扫描开始时最新已完成交易日，包含中美节假日和提前收盘。
扫描期间跨越收盘仍保持同一次扫描的固定截止日；下一次扫描再纳入新日线。
个股日线缺少目标交易日则剔除并报告错误，全部历史获取失败时整个扫描报错，不返回“零候选成功”。
日历超出支持范围会报错，需更新 `exchange-calendars`，不会猜测节假日。

`snapshot_price` 保留刚请求到的快照价，`price` 仍为形态计算所用复权日线收盘价。
报告另有 `scan_started_at`、`snapshot_retrieved_at`、`expected_daily_session` 和 `freshness_policy`。
抓取时间不是供应商报价时间：免费数据可能延迟；当前接口不是逐笔实时行情订阅。快照未给报价时间时，无法认证其逐秒新鲜度，不能标为交易所实时价格。

v1.2 在线全历史验证：600519 取得 2001-08-27 至 2026-09-04 的 6159 根日线；AAPL 取得 1980-12-12 至 2026-09-04 的 11525 根日线。相关自动化回归测试 56 项通过。
验证报告：`data/lifecycle-all-history-live-2026-09-04.json`。仅验证指定样本，不冒充已完成全市场扫描。

以下 v1.1 规则和实测为历史记录，五年上限及缓存说明已被上述 v1.2 行为替代；旧分数不代表当前全历史模型结果。

策略名 `lifecycle_ah`，接入 AlphaSift 的策略加载、双市场筛选、评分和 Pick 输出。
本版识别 A/H，不宣称已完成 B–G 全阶段分类，也不代表收益回测已经通过。

## v1.1 规则记录

- 使用同一复权口径 OHLCV，最多 1260 个交易日，默认至少 504 个交易日。
- 周线采用周五周期；只用已经完成的周线。局部极值必须经左右各 4 周确认，存在确认延迟。
- A 门槛：不满足完整 H 结构；距 52 周低点不超过 20%、距观察窗口最低点不超过 35%；最近 60 日内发生过 20 日跌幅至少 12% 或 60 日跌幅至少 22% 的杀跌；杀跌前 120 日涨幅不超过 10%，且此前震荡区间不超过 60% 或持续下行。
- H 结构门槛：D 前上涨至少 100%；现价从 D 回撤至少 50%；D 后至少三个已确认反弹高点构成连续两次 Lower High（相邻降低超过 2%）；200 日均线斜率向下；距 D 至少约半年。
- H 当前位置还必须距 52 周低点和 D 后最低点均不超过 20%，且出现加速下跌。加速定义：20 日收益小于 `min(-8%, 60日收益/3)`，或 60 日收益小于 -20%。
- `near_52w_low_pct: 10` 是理想低位尺度，硬门槛使用其两倍以容纳刚启动形态；因此 10%–20% 的候选并非最理想低位。
- A/H 资格先于评分，缺少结构的股票即使分数高也不会进入榜单；两类互斥，不足 20 只不凑数。

评分综合价格位置、趋势、恐慌跌幅、止跌、Wilder RSI14、MACD、量能和 RSI 底背离。
H 另计主升幅度、D 后回撤与连续 Lower High/Lower Low。分数在 0–100 内，不是胜率；A 的技术分最高 95，未凭空添加 5 分“基本面安全分”。
输出同时保留 MA20/50/200、MA200 斜率、ATR14%、历史最大回撤、D 点日期和已确认周线拐点用于审计；ATR 不单独决定入选。

## 数据和风险边界

完整策略使用正常快照硬筛（排除 ST、价格至少 1、日成交额至少 2000 万），美股要求美元市值至少 10 亿。
已知退市、破产、造假风险标记直接剔除，但未接入完整公告/财报核验，不能把没有风险标记解释成安全。
基本面状态明确为 `unverified`，只输出“① 左侧观察”或“③ A/H附近但尚未止跌”；不自动输出试仓/加仓，也不伪造基本面 Top 10。

日线输出交易日期 `data_as_of`；供应商未提供准确报价时间时 `data_timestamp` 留空。
Yahoo 下载结束日为排他边界，已改为当地次日，并剔除当地正常收盘前的当日日线。
这不是交易所实时行情；提前收盘日可能保守等待正常收盘时间。策略拒绝已标记陈旧的缓存，但不会自动识别所有市场假期或供应商延迟；务必核对日期。
验证命令用显式 `--as-of` 检验每一只股票，不符合指定交易日的记录不进入验证榜单。

## 使用

在 AlphaSift 目录、依赖已安装的 Python 环境执行：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
$env:DAILY_SOURCE = 'yfinance'
python -m alphasift.cli screen lifecycle_ah --market cn --no-llm
python -m alphasift.cli screen lifecycle_ah --market us --no-llm
python -m alphasift.validate_lifecycle --as-of 2026-09-04 --output data/lifecycle-validation-2026-09-04.json
python -m alphasift.validate_lifecycle --as-of 2026-09-04 --input-dir data/lifecycle-validation-2026-09-04-histories --output data/lifecycle-replay-2026-09-04.json
```

验证工具可通过 `--cn 000858,603501`、`--us AAPL,MSFT` 替换样本。验证工具直接检验技术模型，不对样本重新执行市值/成交额或基本面筛选；它不是完整策略全市场运行的替代品。
使用实时数据重新验证时，应把日期换成两个市场实际已完成的目标交易日；两地休市不同则分别验证。
